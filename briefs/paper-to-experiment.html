Paper → Experiment

Planned concept · not implemented

Planned concept, not yet implemented. I want to build a small agent workflow that extracts a paper's claims, links them to supporting passages, proposes a minimal reproduction experiment, and critiques missing assumptions. The initial scope would produce an experiment specification from one open-access paper, with human review before code execution.

The problem

Planned investigation: moving from an ML paper to a reproduction requires extracting the claims, identifying assumptions, and specifying what evidence an experiment should produce.

Proposed approach

  • Select one open-access paper and plan a passage-level evidence index.
  • Extract the principal claims and link each one to supporting passages.
  • Generate a minimal reproduction specification with data, method, and evaluation requirements.
  • Critique missing assumptions and require human review before any proposed code execution.

Planned contribution: implement claim extraction, citation mapping, and experiment-plan review.

Proposed evaluation

Planned first milestone: a cited reproduction plan for one paper. No completed experiments or results yet.

Proposed evaluation only: claim-to-passage accuracy, completeness of the experiment specification, and whether missing assumptions are surfaced. No completed experiments or measurements exist.

Scope & next steps

This project is a planned weekend lab, not published research.

First, choose one open-access paper with a manageable experiment.

System workflow

High-level proposed workflow.

  1. Open-access paper — Proposed: start with one open-access ML paper.
  2. Extract cited claims — Proposed: extract claims with citations to supporting passages.
  3. Plan experiment — Proposed: create a minimal experiment plan from the cited claims.
  4. Review assumptions — Proposed: review assumptions and resource needs before executing anything.

Proposed focus: Citation grounding · Experiment planning · Reproducibility
