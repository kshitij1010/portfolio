Reading cognitive load

Documented work

At the Johns Hopkins ARCADE Lab, I developed personalized machine learning models for real-time cognitive load estimation in telerobotic surgery. The work combined pupillometry, gaze entropy, and brightness-aware feature engineering with Random Forest models to improve classification robustness.

The problem

Estimating cognitive load during telerobotic surgery requires physiological signals to be interpreted in context. Brightness can affect pupil measurements, motivating brightness-aware modeling.

Approach & contribution

  • Develop personalized models for real-time cognitive load estimation in the telerobotic surgery setting.
  • Use pupillometry and gaze information as physiological inputs.
  • Engineer brightness-aware features and gaze entropy measures.
  • Apply Random Forest classification to improve robustness and reduce misclassification.

Developed personalized machine learning models as a Research Assistant at the JHU ARCADE Lab.

Outcome & evidence

Resume-reported result: 20% reduction in cognitive load misclassification.
