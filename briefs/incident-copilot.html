Incident Flight Recorder

Planned concept · not implemented

Planned concept, not yet implemented. I want to build an agent that investigates a simulated service incident using read-only log tools and retrieved runbooks, then assembles an evidence-linked timeline and suggested next steps. Any proposed change would stop at a human approval gate. The weekend scope would use a local demo service and synthetic incidents.

The problem

Planned investigation: incident triage often requires connecting alerts, logs, and runbooks. A bounded assistant could help assemble evidence while leaving proposed changes for human review.

Proposed approach

  • Plan a local demo service with one synthetic incident and a small runbook collection.
  • Expose read-only diagnostic tools for retrieving the relevant logs and service context.
  • Build an agent workflow that links each timeline event and recommendation to evidence.
  • Stop proposed changes at a human approval gate and record tool-call limits.

Planned contribution: build the synthetic incident, diagnostic tool interface, and cited investigation workflow.

Proposed evaluation

Planned first milestone: one simulated incident investigated end to end. No deployment or operational claims yet.

Proposed evaluation only: whether the timeline matches the synthetic incident, recommendations cite the correct evidence, and the workflow respects read-only tools and call limits.

Scope & next steps

This is a planned weekend concept with no implementation yet.

First, create one deterministic failure in a local demo service.

System workflow

High-level proposed workflow.

  1. Simulated alert — Proposed: begin with a synthetic incident and a simulated alert.
  2. Retrieve evidence — Proposed: gather evidence through read-only retrieval tools.
  3. Build timeline — Proposed: construct a timeline linked to the retrieved evidence.
  4. Request approval — Proposed: present findings and request human approval for any suggested changes.

Proposed focus: Log retrieval · Read-only tools · Human approval
