RETRIEVAL & REASONING · Fall 2024

Financial RAG, with context

Documented work

Built an end-to-end financial document intelligence and evaluation pipeline with Llama 3.2, LangChain, and FAISS. Query rewriting, hybrid retrieval, and maximal marginal relevance improve document selection. A custom HTMLTableAwareTextSplitter preserves table structure instead of flattening away relationships.

The problem

Financial reports combine prose and tables. Flattening table structure can remove the relationships needed to retrieve the right evidence and answer a financial document question.

Approach & contribution

  • Build the RAG pipeline using Llama 3.2, LangChain, and FAISS.
  • Rewrite queries and combine retrieval methods to improve document selection.
  • Use maximal marginal relevance to select useful context for document reasoning.
  • Implement HTMLTableAwareTextSplitter to retain structured tabular context.
  • Evaluate retrieval behavior on financial reports.

System workflow

High-level documented workflow.

  1. Rewrite query — Query rewriting prepares financial questions for retrieval.
  2. Hybrid retrieval — Hybrid retrieval works with table-aware document splitting to preserve useful financial context.
  3. MMR — Maximal Marginal Relevance selects a more diverse set of retrieved passages.
  4. Grounded answer — Llama 3.2 uses retrieved context through a LangChain/FAISS-based workflow.
