LOCAL FOUNDATION MODELS · 2026

A more personal AI

Documented work

A personal AI assistant built around a local Llama 3.2 3B model, fine-tuned using LoRA and Unsloth. The project brings together training and inference workflows with personalized retrieval, ranking, local model serving, and preference learning.

The problem

A personal assistant needs to adapt both the information it retrieves and the behavior of the model responding. This project explores that combination with local model serving.

Approach & contribution

  • Fine-tune a local Llama 3.2 3B model using LoRA and Unsloth.
  • Build the training-to-inference workflow around the adapted model.
  • Develop personalized retrieval and ranking to select useful context.
  • Connect local serving and preference learning within the assistant workflow.

Built the local model fine-tuning and inference workflow.

System workflow

High-level documented workflow.

  1. Personal context — Personal context informs a local assistant designed around the person using it.
  2. Retrieve & rank — Personalized retrieval and ranking select context for the assistant.
  3. Local model — The documented project uses Llama 3.2 3B, LoRA, Unsloth, and local serving.
  4. Respond — Generate responses that reflect retrieved context and explored model adaptations.
