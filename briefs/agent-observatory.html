Agent Observatory

Planned concept · not implemented

Planned concept, not yet implemented. I want to build an evaluation harness that replays agent traces against synthetic tool failures, misleading retrieved text, and strict token budgets. The first milestone would be a small reproducible task suite with a dashboard comparing task success, tool calls, latency, and cost.

The problem

Planned investigation: a successful agent demo does not explain how it behaves when tools fail, retrieved context is misleading, or the token budget is tight.

Proposed approach

  • Plan a small synthetic task suite with explicit success criteria and expected evidence.
  • Design trace capture and replay for model decisions and tool calls.
  • Introduce controlled tool failures and misleading context to test recovery behavior.
  • Compare success, latency, tool calls, and token cost across repeatable runs.

Planned contribution: design the task suite, replay harness, and evaluation dashboard.

Proposed evaluation
